# Traducteur Gen Z → Gen Y

Une application web simple et élégante pour traduire les expressions de la génération Z vers celles de la génération Y.

## Description

Cette application aide à combler le fossé générationnel en traduisant les expressions et le slang de la Gen Z en langage compréhensible pour la Gen Y. Elle comprend un dictionnaire complet de plus de 80 expressions courantes.

## Fonctionnalités

- **Traduction en temps réel** : Entrez du texte contenant des expressions Gen Z et obtenez une traduction instantanée
- **Dictionnaire complet** : Plus de 80 expressions Gen Z avec leurs équivalents Gen Y
- **Interface moderne** : Design épuré et responsive avec dégradés colorés
- **Facile à utiliser** : Interface intuitive avec boutons de traduction et d'effacement

## Comment utiliser

1. Ouvrez le fichier `index.html` dans votre navigateur web
2. Entrez une expression Gen Z dans la zone de texte (ex: "C'est trop slay frr no cap")
3. Cliquez sur le bouton "Traduire →" ou utilisez Ctrl+Entrée
4. La traduction apparaîtra dans la zone de sortie
5. Consultez le dictionnaire en bas de page pour voir toutes les expressions disponibles

## Exemples d'expressions traduites

- **slay** → c'est génial / tu assures
- **frr** → franchement / vraiment
- **no cap** → sans mentir / vraiment
- **bussin** → délicieux / excellent
- **sheesh** → wow / incroyable
- **cringe** → gênant / embarrassant
- **vibe** → ambiance / feeling
- **ghosting** → ignorer quelqu'un soudainement

3. Dans le menu de gauche, cliquez sur **Pages**
4. Sous **Source**, sélectionnez :

   - **Folder** : `/ (root)`

Votre site sera alors accessible publiquement en ligne !
